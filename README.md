
# Skill Swap

## About the Project

Skill Swap is a web application built using Django that allows users to share their skills and learn new skills from other people.

Users can create an account, add skills they can teach, list skills they want to learn, browse skills shared by other users, and send skill exchange requests.

## Features

- User registration and login
- Personal dashboard
- Add skills to teach or learn
- View your own skills
- Browse other users' skills
- Filter skills by type
- Send skill exchange requests
- Accept or reject incoming requests

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## Purpose

This project was created to practice Django web development, database models, forms, user authentication, views, URL routing, and templates.


## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Create a virtual environment:

   python -m venv venv

4. Activate the virtual environment on Windows:

   venv\Scripts\activate

5. Install Django:

   pip install django

6. Apply database migrations:

   python manage.py migrate

7. Start the development server:

   python manage.py runserver

8. Open http://127.0.0.1:8000/ in your browser.
